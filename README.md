# 护肤智选 (SkinMatch)

基于 Sephora 产品数据的智能护肤品推荐应用。根据用户肤质特征、肌肤困扰和产品需求，结合成分分析、评分和用户评价进行个性化推荐。

## 功能

- **多语言界面**：支持中文、English、Français 一键切换
- **产品数据采集**：从 Sephora 抓取产品成分、评分和用户评价（含 23 款本地种子数据作为后备）
- **肤质问卷**：肤质类型、肌肤困扰（下垂、细纹、干燥、色斑、痘痘、出油等）、产品类别、预算、年龄段
- **智能推荐**：基于成分匹配、评分权重和评价情感分析的多维度推荐算法
- **详细展示**：成分、功效、来源网站、运费、评分、好评/差评摘要、匹配理由、Sephora 购买链接

## 技术栈

- **后端**：Python + FastAPI + BeautifulSoup（网页抓取）
- **前端**：React + TypeScript + Tailwind CSS + Vite

## 推荐逻辑说明

- **不同肤质/困扰/预算** → 推荐结果不同
- **相同条件** → 每次推荐略有变化（从匹配度最高的 15 款中随机选 5 款）
- 展示顺序：**评分从高到低**，评分相同时 **价格从低到高**
- 每个类别展示评分最高的 **5 款** 产品（产品库共 **251 款**）

## 快速启动（本地开发）

```bash
# 安装依赖
cd backend && pip install -r requirements.txt
cd ../frontend && npm install

# 一键启动（前后端）
chmod +x start.sh
./start.sh
```

或分别启动：

```bash
# 后端 (端口 8000)
cd backend && uvicorn main:app --reload --port 8000

# 前端 (端口 5173)
cd frontend && npm run dev
```

访问 http://localhost:5173 使用应用。

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/meta?lang=en\|fr\|zh` | GET | 获取肤质、困扰、类别选项（多语言） |
| `/api/products` | GET | 获取产品列表 |
| `/api/recommend?lang=...` | POST | 提交肤质信息获取推荐 |
| `/api/scrape/refresh` | POST | 从 Sephora 刷新产品数据 |

## 推荐算法

1. **成分匹配**：根据肤质和困扰匹配有益成分（如烟酰胺→控油/毛孔，玻尿酸→保湿/细纹）
2. **评分权重**：高评分产品获得更高推荐权重
3. **评价分析**：从用户好评/差评中提取与用户需求相关的信息
4. **年龄段加权**：35+ 用户优先推荐含视黄醇、胜肽等抗老成分的产品
5. **注意事项**：敏感肌自动检测刺激成分，预算超限产品自动过滤
